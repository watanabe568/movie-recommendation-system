# 映画推薦システム（Movie Recommendation System）

## 概要
本システムは、ユーザーが選択した映画の情報をもとに、  
類似した映画を推薦する **Webベースの映画推薦システム** です。

Python と Flask を用いて実装し、  
映画の評価データを利用した **簡易的なレコメンデーション機能** を提供します。

---

## 使用技術
- Python 3
- Flask
- HTML / CSS
- 協調フィルタリング（簡易ロジック）

---

## 機能一覧
- 映画一覧の表示
- ユーザーが選択した映画に基づくおすすめ映画の表示
- 映画が未選択の場合は、評価が高い映画を推薦

---

## 動作イメージ
1. 映画一覧から好きな映画を複数選択  
2. 「おすすめ映画を表示」ボタンをクリック  
3. 選択内容に基づいた映画が表示される  

※ 映画を選択しなかった場合は、評価の高い映画が表示されます。
